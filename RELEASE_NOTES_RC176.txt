Bass Stem Studio RC176

Smooth loops
Enabled by default. Short output fades soften clicks at loop boundaries.
Works with the existing playback, section repeat and time-cell repeat paths.
The switch remembers your preference. Audio and pitch remain unchanged in saved source files.
This reduces boundary clicks; browser media seeking can still cause a small gap.

Keep awake
Enabled by default. Requests a screen wake lock during playback, live audio,
ear training, chord review and sound check. Releases it when practice stops
or the page is hidden. Switch off to allow normal screen dimming.
Requires a supported browser and secure context (HTTPS or localhost).
Battery policy or the operating system may release or refuse the lock.
A short status shows availability; this is not a background-playback feature.

Interface
Two concise, padded controls below the essential practice buttons.
Existing More tools grouping, centred headings and button sizing retained.
